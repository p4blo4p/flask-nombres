Sobre {{ cfg.site_name }}

{{ cfg.site_name }} es un diccionario digital de significados de nombres. Cada entrada documenta el origen lingüístico, la etimología, las variantes en otros idiomas, las figuras históricas que llevaron el nombre y una curiosidad destacada.

Para quién es

  • Padres y madres buscando el nombre de un bebé.
  • Personas curiosas por el significado de su propio nombre.
  • Estudiantes de lingüística, antroponimia o historia.
  • Escritores y creadores buscando nombres con significado para sus personajes.

Cómo está hecho

El sitio está generado estáticamente con Flask y Frozen-Flask a partir de un archivo JSON de datos. Esto significa que el contenido se sirve como HTML, CSS y JavaScript planos, sin servidor ni base de datos en producción: rápido, barato (hosting gratis en GitHub Pages) y excelente para SEO.

Fuentes

Las etimologías siguen obras de referencia estándar sobre antroponimía (diccionarios etimológicos de nombres propios, Behind the Name, repertorios de santoral). Las «características» asociadas a cada nombre son tradiciones populares reflejadas en manuales de nombres, no afirmaciones psicológicas verificadas científicamente.

Contacto

Si detectas un error en una etimología o quieres proponer un nombre nuevo, abre una issue en el repositorio del proyecto en GitHub.
